# 見積書テンプレート（日本版）

> 使い方：分析レポートの数値をそのまま転記する。空欄は「—」ではなく「要確認」と書く。
> 三段固定：材料費 + 機時/工数 + 失敗保険（作り直し1回分を先に積む）。

## 1. 前提

- 対象モデル：{fileName}（{triangles}面）
- 寸法：{x} × {y} × {z} mm / 体積：{volume}（非水密の場合は「体積未確定・修復後再見積」と明記）
- 工法：{process} / 材料：{material} / 積層ピッチ：{layerHeight} / 充填率：{infill}

## 2. 内訳

| 項目 | 数量 | 単価 | 金額 |
|------|------|------|------|
| 材料費（{material}、サポート込） | {weight}g | ¥{pricePerKg}/kg | ¥{materialCost} |
| 機時（{hours}h、段取り込） | {hours}h | ¥{machineRate}/h | ¥{machineCost} |
| 後処理（サポート除去・研磨） | 一式 | — | ¥{postCost} |
| 失敗保険（作り直し1回分・上限） | 1回 | — | ¥{riskCost} |
| **合計（税別）** | | | **¥{total}** |

## 3. 納期と条件

- 納期：{deliveryDate}（修復待ち日数は含まず）
- 納品物：現品 + プリント分析レポート（CLIENT SUMMARY）+ 寸法写真
- 保証：到着後7日以内の造形不良は失敗保険で1回無償作り直し
- 対象外：設計変更、熱/FEA未解析領域、実機キャリブレーション差

## 4. 一言添え（現状リスクが高い場合）

> 現状のままでは印刷失敗リスクが高いため、最安の次の一手は「{cheapestStep}」です。
> 実施後に再出力したレポートで正式見積とします。
